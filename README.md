# Clinical Trial Finder

A planned Python command-line app for searching public study records from [ClinicalTrials.gov](https://clinicaltrials.gov/data-api/api).

The app will search by condition, intervention, study location, and overall recruiting status. Users will be able to see what each filter matches, save named searches locally, and rerun them against current records.

## Development status

This repository scaffold defines the project scope. The next increment adds a Python entry point. Later increments will add API requests, JSON output, saved searches, error handling, and tests.
